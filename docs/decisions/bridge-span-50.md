# Mine bridge span limit

Both dry and non-lava water gaps are limited to 50 missing-floor tunnel slices. The construction footprint may extend three slices into each landing beyond this gap limit.

The existing whole-span builder uses a fixed NPC work target; reliable placement and traversal over 50 slices are not yet proven by an in-game test. The boundary regression tests cover 16, 30, 50 and 51 slices.
